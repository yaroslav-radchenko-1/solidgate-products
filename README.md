# Vibe Project Template

A starter template for building full-stack web applications with AI assistance — no programming experience required.

The idea is simple: you describe what you want to build, and Claude writes the code for you. This template gives Claude a ready-made foundation with a frontend and backend already connected, so you can start building features right away instead of spending time on setup.

## What's inside

| Layer | Technology |
|-------|-----------|
| Frontend | [Vue 3](https://vuejs.org/) — the user interface |
| Backend | [NestJS](https://nestjs.com/) — the API server |
| Language | TypeScript throughout |
| Build tool | Vite (frontend), tsc (backend) |

In development, the frontend runs on port **5173** and the backend on port **3000**. In production, everything is served from a single port.

## Getting started

Full guide on how to create and work with projects from this template: [How to vibe code project](https://www.notion.so/skelar/How-to-vibe-code-project-32dfe0c4a15b80dfa502fa06ba30dd7a)

## Useful commands

All commands are run inside Claude Code by typing `/command-name`:

| Command | What it does |
|---------|-------------|
| `/setup` | Install dependencies and launch the app |
| `/save` | Save and upload all changes to GitHub |
| `/sync` | Download latest changes from GitHub |
| `/lint` | Fix all code style issues |
